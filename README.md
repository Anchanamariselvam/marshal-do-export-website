# MARSHAL DO EXPORT Website

A website project for MARSHAL DO EXPORT, built using React, TypeScript, and Vite.

## Technologies Used

- React
- TypeScript
- Vite
- CSS

## Getting Started

### Prerequisites

Install Node.js and npm.

### Installation

Install the project dependencies:

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

The terminal will display the local development URL.

### Build for Production

```bash
npm run build
```

The production build will be generated in the `dist` directory.
